# Gift Store - User Stories

## User Story Template

**As a** [user role]

**I want** [goal or action]

**So that** [reason or benefit]

---

## User Stories

### User Story 1
**As a** customer  
**I want** to register for an account  
**So that** I can access the gift store and place orders.

### User Story 2
**As a** customer  
**I want** to log in to my account  
**So that** I can access my personal information and orders.

### User Story 3
**As a** customer  
**I want** to view all available gifts  
**So that** I can choose a suitable gift.

### User Story 4
**As a** customer  
**I want** to view the details of a gift  
**So that** I can make an informed purchasing decision.

### User Story 5
**As a** customer  
**I want** to search for gifts  
**So that** I can quickly find products matching my needs.

### User Story 6
**As a** customer  
**I want** to filter gifts by category  
**So that** I can easily browse relevant products.

### User Story 7
**As a** customer  
**I want** to update my account information  
**So that** my personal information remains current.

### User Story 8
**As a** customer  
**I want** to securely authenticate  
**So that** my account information is protected.

### User Story 9
**As a** customer  
**I want** to access the application through a deployed website  
**So that** I can use the gift store online.

### User Story 10
**As a** developer  
**I want** automated CI/CD  
**So that** application changes can be tested and deployed reliably.
